# Reporting a security problem

Protégé is used with students, so security problems are fixed first.

**Please report privately**, not in a public issue: use GitHub's **"Report a vulnerability"** button on the
**Security** tab of the Protégé repository. Include what you found, how to reproduce it, and what someone
could do with it. You'll get a reply within a week.

Please don't test against a school's real Protégé, or access anyone's data. Run your own copy (see the
README); it's free.

What's in scope: anything that could let someone see or change another person's information, sign in as
someone else, run code on the computer running Protégé, or get around the safety filters that protect
students.

How Protégé is secured is described in [docs/board/security.md](docs/board/security.md).
